# Oxide Editor のタスク実行

Oxide Editor は、ワークスペース直下の `.oxide/tasks.json` を優先し、存在しない場合は `.vscode/tasks.json` から名前付きタスクを読み込みます。コマンドパレットの **Tasks: Run Task** からタスクを選択すると、アクティブワークスペースを作業ディレクトリとして実行し、標準出力・標準エラー出力を Output パネルへ表示します。

## タスク形式

```json
{
  "tasks": [
    {
      "label": "Python: pytest",
      "command": "pytest",
      "args": ["-q"],
      "cwd": ".",
      "env": {
        "PYTHONUNBUFFERED": "1"
      },
      "dependsOn": ["Python: install dependencies"],
      "is_background": false
    },
    {
      "label": "Python: install dependencies",
      "command": "python",
      "args": ["-m", "pip", "install", "-r", "requirements.txt"]
    }
  ]
}
```

| フィールド      |   必須 | 説明                                                                     |
| --------------- | -----: | ------------------------------------------------------------------------ |
| `label`         |   はい | ワークスペース内で一意の表示名。                                         |
| `command`       |   はい | 実行ファイル名またはコマンドパス。                                       |
| `args`          | いいえ | コマンドへ渡す引数の配列。                                               |
| `cwd`           | いいえ | ワークスペース配下の作業ディレクトリ。指定しない場合はアクティブルート。 |
| `env`           | いいえ | 追加または上書きする環境変数。秘密情報を含めない。                       |
| `dependsOn`     | いいえ | 事前に存在を検証する依存タスク名。                                       |
| `is_background` | いいえ | バックグラウンド種別を表す予約フィールド。                               |

タスク定義を読み込む際、空のラベル・コマンド、重複するラベル、存在しない依存タスクを拒否します。`cwd` は正規化してアクティブルートの内側にあることを確認するため、ワークスペース外では実行できません。

## Problems への連携

出力行が `error` または `warning` で始まる場合、Problems として扱います。さらに、次の形式のコンパイラ診断は、ファイル・行・列を抽出します。

```text
src/main.rs:12:8: error: expected expression
```

## セキュリティと現在の制約

タスクはプロジェクトのコマンドを実行します。未信頼ワークスペースを制限する機能と併用する場合は、タスク実行前に明示的な信頼確認を行ってください。環境変数や設定ファイルにアクセストークン、パスワード、秘密鍵を保存しないでください。

現時点では、依存タスクの自動実行、標準入力の対話、バックグラウンドプロセスの停止・状態管理、履歴、キーバインド、個別テストの実行は後続の実装対象です。`dependsOn` と `is_background` は設定互換性と検証のために受け付けますが、それ自体が自動実行・監視を有効化するものではありません。
