> **文書ステータス — 事前調査記録**: 本書は技術選定時の比較・仮説を保存するものであり、現行実装、性能測定、互換性、採用済みの設計を示しません。現在の実装状況は [プロジェクト状況](../project-status.md) を参照してください。本文の数値は、測定手順と結果が別途示されない限り、目標値または調査時点の推定です。

> 本ドキュメントは、Microsoft VS Code（Electron / Chromium / Node.js 基盤）を Rust 製ネイティブデスクトップフレームワークへ完全置換・移植するための技術選定調査書です。

---

## 1. 調査背景と要件

VS Code は Electron を基盤とすることで高い開発生産性とクロスプラットフォーム対応を実現していますが、以下の課題を抱えています：
- **メモリ消費量:** Chromium + Node.js ランタイムにより、起動直後で 300MB〜800MB を消費
- **起動オーバーヘッド:** プロセス起動と V8 JIT コンパイルにより、起動に 1.5秒〜3.0秒 を要する
- **DOM レンダリング限界:** 巨大ファイル（100MB+）での DOM ノード生成負荷とガベージコレクション（GC）によるフレーム落ち

**Rust による置換ターゲット要件:**
1. **起動時間 100ms 以下、常駐メモリ 50MB 以下の極小リソース**
2. **GPU 加速による 120fps+ の低遅延テキストレンダリング**
3. **VS Code の複雑な Workbench（ActivityBar, SideBar, Grid Editor, Panel, QuickPick）の完全な表現力**
4. **マルチウィンドウ、ドラッグ&ドロップ、ネイティブメニュー、PTY 端末の完全サポート**

## 3. 各フレームワークの深掘り分析

### 3.1 候補 1: GPUI (Zed 製 GPU ネイティブ UI フレームワーク)
- **概要:** 高速エディタ Zed を支える Rust 製 UI フレームワーク。Metal (macOS), Vulkan / Direct3D (Windows/Linux) ネイティブ。
- **強み:**
  - VS Code と同様のコンポーネントツリー、非同期タスク、Model-View-Update をネイティブ GPU レンダリングで実現。
  - テキスト成形（HarfBuzz）と GPU グリフキャッシュが標準装備されており、エディタ用途に最適化されている。
- **課題:**
  - Windows / Linux サポートが急速に進行中だが、macOS 以外のプラットフォームでの成熟度を検証する必要がある。

### 3.2 候補 2: Egui + WGPU (イミディエイトモード GPU レンダラ)
- **概要:** 軽量で依存関係が少なく、WGPU 上で動作する即時描画 UI。
- **強み:**
  - 状態管理がシンプルで、バグが混入しにくい。
  - 常駐メモリ 25MB 前後、高速起動、クロスプラットフォームで安定動作。
- **課題:**
  - 大規模な DOM 風の複雑なネストレイアウト（リサイズ可能な多段スプリットグリッド）の実装に工夫が必要。

### 3.3 候補 3: Tauri v2 (Rust + 最適化 WebView / Winit)
- **概要:** バックエンドを Rust で記述し、フロントエンドにシステム標準の WebView（WebView2 / WebKit）を使用。
- **強み:**
  - VS Code の既存の Web / CSS アセットや Monaco Editor を直接再利用可能。
  - 最も早く完全な UI 互換性を達成できる。
- **課題:**
  - ピュア Rust ネイティブ（GPU 描画）に比べると、WebView2 プロセスが常駐するためメモリが 80MB〜120MB 程度必要。

## 4. 推薦・選定方針

### 🏆 推奨アーキテクチャ: **ハイブリッド段階的アプローチ**

1. **第 1 段階 (基盤 & コア設計):**
   - UI フレームワークに依存しない **コアサービス層（`oxide-base`, `oxide-platform`, `oxide-editor`）をピュア Rust で構築**。
   - Monaco Editor のテキストモデル（Ropey / PieceTree）、LSP クライアント、Git 管理、PTY 端末、Extension Host は UI 独立で共通化。
2. **第 2 段階 (UI レイヤ選定):**
   - **ネイティブ GPU 版 (`oxide-gpui` / `oxide-egui`):** メモリ 30MB、120fps の究極のパフォーマンスを追求するネイティブ版。
   - **プラグイン互換性:** VS Code API (`vscode.*`) をエミュレートし、`.vsix` 拡張機能を WASM / V8 サンドボックスで実行。
