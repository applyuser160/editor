# アクセシビリティと国際化

Oxide Editor は **WCAG 2.2 AA** を設計基準とし、キーボードだけの操作、支援技術、配色、拡大表示、モーション、IME、日英ロケールを継続的に検証します。実装の設定はネイティブ設定ストアへ保存され、再起動せずに反映されます。

## 利用者向けの設定

| 設定 | 効果 | 反映範囲 |
|---|---|---|
| 表示言語 | 日本語と英語を切り替えます。未翻訳キーは日本語へフォールバックします。 | 主要メニュー、活動バーのアクセシブルネーム、パネル、検索導線 |
| フォントサイズ | 10–28 px のエディター文字サイズを設定します。 | Monaco エディターとアプリケーションの基準文字サイズ |
| ハイコントラスト | 高コントラストのテーマ、境界、フォーカスリングを有効にします。 | 全画面 |
| モーションを減らす | アニメーションと遷移を最小化します。OS の `prefers-reduced-motion` も尊重します。 | 全画面 |

## キーボードとスクリーンリーダー

スキップリンクを使用すると、タイトルバーを経由せずにメイン編集領域へ移動できます。メニュー、活動バー、パネルタブ、設定、SCM の操作ボタンはフォーカス可能なネイティブ要素を用い、`focus-visible` の視覚表示を提供します。クイックオープン、保存確認、差分プレビュー、マージ支援などのモーダルはダイアログとして扱い、Tab と Shift+Tab でフォーカスがモーダル内を循環します。

操作結果、保存状況、エラー、トースト通知はライブリージョンへ送られます。重大なエラーは `alert` として、通常の完了通知は `status` として通知します。

## IME 検証

日本語、中国語、韓国語の候補選択・確定中は、ブラウザが `isComposing` またはキーコード 229 を通知します。Oxide Editor のグローバルショートカットはこの間に実行されず、Monaco と xterm.js の入力を妨げません。各リリースでは次の組合せを手動確認します。

| OS | IME | 確認内容 |
|---|---|---|
| Windows | Microsoft IME、Microsoft Pinyin、Microsoft Korean IME | 編集、変換候補、確定、ショートカット抑制 |
| macOS | 日本語、簡体字中国語、韓国語 | 編集、変換候補、確定、モーダル遷移 |
| Linux | IBus または Fcitx5 の日本語・中国語・韓国語 | Monaco、xterm.js、検索欄、設定欄での入力 |

## リリース確認項目

主要操作は Tab、Shift+Tab、Enter、Escape、矢印キー、既定ショートカットだけで完結することを確認します。スクリーンリーダーでは、メニュー、ツリー、Problems、SCM、モーダルの名前・役割・状態・操作結果が読み上げられることを確認します。200% の拡大と高コントラストで重要な操作が隠れないこと、低モーション設定で不要な動きが抑制されること、日英切替で表示言語がただちに更新されることを確認します。
