# Oxide Editor の拡張機能ライフサイクル

Oxide Editor はOpen VSXから取得したVSIXを、ローカルの拡張機能レジストリとして管理します。本実装は、拡張機能を**検証、展開、永続化、有効・無効化、削除**するライフサイクルを提供します。VS Code Extension APIとの完全互換や任意JavaScriptの実行は、この段階では提供しません。

## インストールフロー

Open VSX検索結果からインストールを選ぶと、VSIXアーカイブを取得し、アーカイブ内の `extension/package.json` または `package.json` を検証します。マニフェストのpublisher、name、versionは英数字、ハイフン、アンダースコア、ドットだけを許可し、Open VSXで選択した識別子と一致しなければ導入を中止します。

アーカイブは50 MiB、エントリ数は10,000件、マニフェストは1 MiBに制限されます。展開時にはZIPエントリが宛先ディレクトリから外へ出ないことを確認し、ステージングディレクトリへ展開してから確定位置へ移動します。これにより、途中失敗で半端なインストールが残ることを防ぎます。

## Marketplace ビュー

サイドバーの拡張機能ビューでは、インストール済み拡張機能とOpen VSXの検索結果を同時に表示します。検索結果にはインストール済み状態を反映し、導入済みの拡張機能は重複インストールできません。インストールまたは有効・無効化が完了すると、一覧と検索結果を再取得して表示状態を更新します。検索入力では短い待ち時間を設け、古い検索結果が新しい結果を上書きしないようにしています。

Open VSXから取得した名前、説明、識別子、詳細情報はHTMLへ挿入する前にエスケープします。カードはマウスだけでなく、フォーカスした状態でEnterまたはSpaceキーを押して詳細を開けます。

## 保存場所と復元

VSIXアーカイブ、展開済みファイル、インストール済みメタデータはOSのローカルアプリデータ以下の `oxide-editor/extensions` に保存します。起動時にメタデータを読み込むため、導入状態、有効・無効状態、マニフェスト由来の言語・テーマ寄与情報は再起動後も維持されます。

組込みのRust言語サポートと既定テーマは削除・無効化できません。利用者が導入した拡張機能は有効・無効化および削除できます。

## 言語サーバーによるシンタックスハイライト

対応言語（Rust、Python、TypeScript、JavaScript、Go）では、言語サーバーの `textDocument/semanticTokens/full` 応答をMonacoのセマンティックトークンプロバイダーへ変換します。言語サーバーの `initialize` 応答から凡例を取得し、識別子、型、関数、キーワード、文字列、数値などのトークンをテーマに反映します。凡例の取得前は標準凡例を使用し、取得後にMonacoへ再描画を通知します。

このハイライトは、拡張機能パッケージを実行する仕組みとは独立しています。ファイルを開く前に、対応する言語サーバー実行ファイルをPATHまたはワークスペースの依存関係から利用できる状態にしてください。ワークスペースが未信頼の場合、セキュリティ上の理由により言語サーバーは起動しません。

## 実行モデル

Node.jsの有無は拡張ランタイムの前提条件として検査しますが、現時点ではVS Codeの `vscode.*` API、activation event実行、任意の拡張JavaScriptの起動を有効にしていません。これは未検証の拡張コードをアプリ本体の権限で実行しないための意図的な境界です。

将来、Extension Hostを追加する場合は、プロセス分離、権限申告、activation eventの明示的な許可、クラッシュ監視、ログ、サポートする寄与ポイントを設計した上で導入します。完全なVS Code API互換を目指すか、限定されたOxide Plugin APIを採用するかは別途ADRで決定します。
