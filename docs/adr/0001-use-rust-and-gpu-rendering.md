# ADR-0001: Rust とネイティブ GPU レンダリングの検討

- **ステータス:** Deferred
- **決定者:** Syun
- **初版作成日:** 2026-08-22
- **状態確認日:** 2026-08-27
- **関連文書:** [プロジェクト状況](../project-status.md)

## コンテキスト

Rust をバックエンドに利用し、将来的にネイティブ GPU レンダラーを採用する選択肢を検討した記録です。現行アプリケーションは Tauri の WebView 上で Monaco を利用しており、`wgpu`、`vello`、ネイティブ GPU テキストレンダラーの依存関係・実装・ベンチマークはありません。

## 検討した選択肢

1. Rust + WGPU / Vello によるネイティブ GPU レンダリング
2. C++ + Qt / Skia
3. Go + Gio / Fyne
4. Tauri (Rust + WebView)

## 現在の判断

Rust は現行バックエンドで利用しています。一方、選択肢 1 の WGPU/Vello 採用は **延期** します。将来採用を再検討する場合は、プロトタイプ、対象プラットフォーム、テキスト編集 API との統合方法、性能・メモリの再現可能な測定結果を新しい ADR に記録します。

## 未検証事項

50 MB 未満のメモリ、60/120 fps、低遅延描画といった数値は、このリポジトリで測定されていません。これらを現行製品の特性として扱いません。
