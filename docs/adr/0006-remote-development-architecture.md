# ADR-0006: リモート開発アーキテクチャ

- **ステータス:** Proposed
- **状態確認日:** 2026-08-27
- **関連文書:** [プロジェクト状況](../project-status.md)

## 決定案

Oxide Editor のリモート開発では、Tauri アプリケーション内で任意の SSH コマンドを直接組み立てず、ローカルの接続管理層と SSH 上の限定的なリモートエージェントを分離する案を検討します。初期対象は SSH ワークスペースとし、Dev Container と WSL は同じ接続抽象を利用する後続段階とします。

## 責務境界の案

ローカル側は接続先の表示、Known Hosts 検証、資格情報参照、接続状態、利用者操作の確認を担当します。秘密鍵のパスフレーズとトークンは OS の資格情報ストアのみで扱い、設定ファイル・ログ・リモートホストへ送らないことを目標とします。リモートエージェントは、明示的に選択されたワークスペース内のファイル I/O、PTY、Git、LSP だけを提供し、要求ごとにワークスペース境界を検証する案です。

## 未実装であることの明示

SSH 接続、Known Hosts 検証、資格情報ストア、リモートエージェント、Dev Container、WSL は現行リポジトリに実装されていません。ここに記載するフローと制約は設計案であり、セキュリティ特性の保証ではありません。実装を始める前に、脅威モデル、認証情報の取り扱い、失敗時の UI、テスト計画を定義した Issue と ADR を更新します。
