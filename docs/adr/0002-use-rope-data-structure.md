# ADR-0002: Ropey テキストバッファの検討

- **ステータス:** Deferred
- **決定者:** Syun
- **初版作成日:** 2026-08-22
- **状態確認日:** 2026-08-27
- **関連文書:** [プロジェクト状況](../project-status.md)

## コンテキスト

巨大ファイル編集向けのテキストバッファとして Ropey を検討した記録です。現行フロントエンドは Monaco Editor のテキストモデルを使用しており、`ropey` クレートは依存関係に含まれていません。

## 検討した選択肢

1. Ropey クレートによる Rope
2. Piece Table
3. Gap Buffer
4. 行単位の配列

## 現在の判断

Ropey の採用は **延期** します。将来の導入は、Monaco から独自の編集コアへ移行する明確な理由、ファイルサイズ・操作パターンを固定したベンチマーク、LSP 座標変換の互換性、メモリ使用量を評価した後に再判断します。

## 未検証事項

大容量ファイルをミリ秒単位で読み込み・編集できるという主張は、現行実装に対する測定結果ではありません。
