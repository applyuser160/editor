# ADR 0001: リモート開発アーキテクチャ

## 決定

Oxide Editor のリモート開発は、Tauriアプリ内で任意のSSHコマンドを直接組み立てる方式ではなく、ローカルの接続管理層とSSH上の限定的なリモートエージェントを分離する。初期対象はSSHワークスペースだけとし、Dev ContainerとWSLは同じ接続抽象を利用する後続段階とする。

## 責務境界

ローカル側は接続先の表示、Known Hosts検証、資格情報参照、接続状態、利用者操作の確認を担当する。秘密鍵のパスフレーズとトークンはOSの資格情報ストアのみで扱い、設定ファイル・ログ・リモートホストへ送らない。リモートエージェントは明示的に選択されたワークスペース内のファイルI/O、PTY、Git、LSPだけを提供し、要求ごとにワークスペース境界を検証する。

## 接続フロー

接続前にホスト鍵をKnown Hostsと照合し、未知または変更された鍵は指紋と接続先を表示して利用者の明示的な承認を必要とする。認証失敗、ネットワーク切断、再接続待機はUI状態として区別する。再接続は保存済みの認証情報を勝手に再送せず、既存の資格情報ハンドルだけを再利用する。

## 段階的な実装

第一段階では、リモートワークスペースの接続状態モデル、SSHファイル一覧・読取・保存、PTYプロキシ、リモートLSPの1経路を実装する。第二段階で切断からの再接続、転送のキャンセル、遅延表示、接続ログを追加する。コンテナとWSLは接続先として識別するが、実行環境の作成・破棄はこのADRの範囲外とする。

## セキュリティ上の制約

ローカルのTauri CapabilityをリモートWebコンテンツへ公開しない。リモート拡張機能はローカル拡張機能と別の実行境界を持ち、リモート接続に対してのみ権限を申告する。ホスト鍵不一致、証明書検証失敗、ワークスペース外パス、資格情報のテキスト送出は接続失敗として扱う。
