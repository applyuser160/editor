# ADR-0003: WASM プラグイン基盤の検討

- **ステータス:** Deferred
- **決定者:** Syun
- **初版作成日:** 2026-08-22
- **状態確認日:** 2026-08-27
- **関連文書:** [拡張機能ライフサイクル](../extension-lifecycle.md)、[#38](https://github.com/applyuser160/editor/issues/38)

## コンテキスト

拡張コードを隔離して実行する候補として WASM/WASI を検討した記録です。現行実装は VSIX の検証、展開、永続化、有効・無効化、削除を扱いますが、WASM ランタイム、任意 JavaScript 実行、`vscode.*` API、権限申告は実装していません。

## 検討した選択肢

1. WASM / WASI (Wasmtime または Extism)
2. 埋め込み Lua
3. 埋め込み JavaScript
4. ネイティブ共有ライブラリ

## 現在の判断

WASM プラグイン基盤の採用は **延期** します。Extension Host を追加する前に、実行モデル、プロセス・権限境界、対応する寄与ポイント、クラッシュ監視、ログ、テスト方針を設計し、別 ADR で採用可否を判断します。

## 未検証事項

WASM によるプラグイン隔離、Capabilities ベースの権限、拡張機能の安全性・性能は、現行アプリケーションで提供・検証されていません。
