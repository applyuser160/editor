# ADR-0004: Tree-sitter と LSP のハイブリッド構文解析の検討

- **ステータス:** Deferred
- **決定者:** Syun
- **初版作成日:** 2026-08-22
- **状態確認日:** 2026-08-27
- **関連文書:** [プロジェクト状況](../project-status.md)

## コンテキスト

Tree-sitter と LSP のセマンティックトークンを組み合わせる構文解析方式を検討した記録です。現行実装には LSP 通信の基盤がありますが、Tree-sitter の依存関係・グラマー・トークン統合はありません。編集表示は Monaco の機能に依存します。

## 検討した選択肢

1. Tree-sitter と LSP セマンティックトークンのハイブリッド
2. TextMate 形式のグラマー
3. LSP セマンティックトークンのみ
4. 自作パーサー

## 現在の判断

Tree-sitter の採用は **延期** します。実際に採用する場合は、対象言語、Monaco との連携点、障害時のフォールバック、編集時の性能測定、LSP との責務分担を定義したうえで再評価します。

## 未検証事項

数ミリ秒の構文解析、60 fps 維持、VS Code 同等のセマンティックハイライトは、現行実装で測定・保証していません。
