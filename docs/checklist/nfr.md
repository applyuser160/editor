# 非機能要件チェックリスト（IPA準拠 - Oxide Editor）

> IPA「非機能要求グレード 2018」をベースにした非機能要件チェックリストです。  
> Rust 製軽量 IDE「Oxide Editor」の特性（省メモリ、高速応答、クロスプラットフォームデスクトップアプリ）に合わせて定義・評価しています。

## 1. 可用性（Availability）

### 1.1 継続性

| # | チェック項目 | 評価 | 目標値 / 詳細 | 備考 |
|---|------------|:----:|-------------|------|
| 1.1.1 | アプリケーションの稼働安定性 | ✅ | 長時間起動（連続 72 時間以上）でもメモリリークやクラッシュが発生しないこと | Rust 所有権モデルと RAII |
| 1.1.2 | プラグインクラッシュ時の本体保護 | ✅ | プラグインが異常終了・タイムアウトしてもエディター本体プロセスは停止せず継続動作すること | WASM サンドボックス |
| 1.1.3 | 編集状態の自動復元（Auto-save / Crash recovery） | ✅ | クラッシュ時でも直前 1 秒以内の編集バッファ状態を WAL（Write-Ahead Log）から復元可能 | ローカル復旧機構 |
| 1.1.4 | 単一障害点の排除 | ✅ | LSP サーバーや Git プロセスのクラッシュ時にも自動再起動またはフォールバック | 独立プロセス分離 |

## 2. 性能・スケーラビリティ（Performance & Scalability）

### 2.1 応答性能・リソース消費

| # | チェック項目 | 評価 | 目標値 / 詳細 | 備考 |
|---|------------|:----:|-------------|------|
| 2.1.1 | コールドスタート起動時間 | ✅ | 起動からエディター入力可能まで 100ms 以下（SSD環境） | VS Code (1〜3秒) に対し大幅高速化 |
| 2.1.2 | アイドル時メモリ消費量 | ✅ | 単一プロジェクト展開時の常駐メモリ 50MB 未満 | Electron (300MB〜1GB) の 1/10 以下 |
| 2.1.3 | タイピング時のキー入力レイテンシ | ✅ | 入力から画面描画まで 8ms 未満（120fps / 144Hz ディスプレイ完全追従） | GPU テキストキャッシュ |
| 2.1.4 | 大容量ファイルオープン時間 | ✅ | 100MB テキストファイルを 500ms 未満で展開 | Ropey ストリーミング読込 |
| 2.1.5 | ワークスペース全体検索速度 | ✅ | 100,000 行規模のプロジェクト検索を 50ms 未満で完了 | ripgrep 並列エンジン統合 |
